# 🌱 Gamificação BraTech

Projeto desenvolvido para o Challenge 2026 da FIAP em parceria com a SoulUp, com foco na criação de uma plataforma de gamificação sustentável que incentiva ações ecológicas através de pontuações, rankings e recompensas.

---

# 📌 Sobre o Projeto

O projeto Gamificação BraTech tem como objetivo criar uma experiência digital interativa que incentive práticas sustentáveis dentro da comunidade SoulUp.

A plataforma permite que usuários realizem ações sustentáveis e acumulem pontos que podem ser convertidos em benefícios reais, promovendo conscientização ambiental e engajamento social.

O sistema foi desenvolvido utilizando HTML5, CSS3 e JavaScript puro, aplicando conceitos de:

- Estrutura semântica
- Responsividade
- Interatividade
- Arquitetura Front-End
- Organização visual
- Experiência do usuário

---

# 🎯 Objetivo da Solução

A proposta do projeto é desenvolver uma interface moderna, intuitiva e responsiva para demonstrar o funcionamento de um sistema de gamificação sustentável.

A solução busca:

- Incentivar hábitos sustentáveis
- Melhorar o engajamento dos usuários
- Demonstrar rankings e recompensas
- Criar uma navegação acessível e organizada
- Simular funcionalidades reais da plataforma SoulUp
