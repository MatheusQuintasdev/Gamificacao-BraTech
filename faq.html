Perguntas Frequentes

O que é o Desafio do Challenge SoulUp?

Trata-se do desenvolvimento de uma interface com um Avatar Inteligente capaz de engajar usuários corporativos em ações ecológicas.

Como a interface ajuda o usuário?

Através de conversas com o Avatar, o usuário recebe dicas diretas sobre redução de consumo de recursos e descarte de resíduos.

O site atende aos critérios de responsividade?

Sim! A estrutura de arquivos CSS foi projetada de forma modular para adaptar as telas a smartphones, tablets e desktops.
